# Security and private data

Do not add credentials, private reference images, customer prompts, personal paths, or unpublished outputs to workflows, issues, commits, screenshots, or installation logs.

These workflows make no paid provider call. They run locally after the operator supplies ComfyUI, custom nodes, and model files. Installation verification must stop before queueing.

Before sharing diagnostics, remove private images, generated images, prompts, paths, usernames, hostnames, and environment details that are not required to reproduce the problem. Report only the package version, relevant node commits, model filenames, and concise error text.

Use the repository's GitHub security reporting feature for sensitive vulnerabilities when available. Use public issues only for reports that contain no sensitive data.
